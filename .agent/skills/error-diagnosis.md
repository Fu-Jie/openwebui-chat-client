# Error Diagnosis Skill

此 Skill 用于分析错误日志或异常堆栈，快速定位问题原因并提供解决方案。

## 输入格式

提供错误日志、异常堆栈信息或错误描述。

## 处理逻辑

1. **识别异常类型**: 分析是网络错误、认证错误、解析错误还是逻辑错误
2. **定位代码位置**: 根据堆栈信息定位到具体的代码行
3. **分析上下文**: 结合操作上下文（如调用的方法、参数）分析原因
4. **提供解决方案**: 给出具体的修复建议或调试步骤

## 输出示例

**错误分析**:
- **类型**: `json.decoder.JSONDecodeError`
- **原因**: API 返回了非 JSON 格式的响应（可能是 HTML 错误页面）
- **可能场景**: 
  - Token 无效导致重定向到登录页
  - Nginx 网关超时 (504 Gateway Time-out)
  - API 端点 URL 错误 (404 Not Found)

**解决方案**:
1. 检查 `response.status_code`，确认是否为 200
2. 打印 `response.text` 查看实际响应内容
3. 验证 API Token 是否有效

## 使用提示

- 在遇到未知错误时使用
- 配合 `/debug-issue` 工作流使用
