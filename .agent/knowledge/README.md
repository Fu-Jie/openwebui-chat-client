# OpenWebUI API Knowledge Base

This directory contains categorized, dual-language (zh/en) documentation of the complete OpenWebUI API behaviors learned by the agent.

本目录包含代理程序在此项目中学习到的全量 OpenWebUI API 结构与行为。所有文档均采用双语（中英）对照编写，以便后续生成新版 SDK。

## Directory Structure (目录结构)

- `api/`: API Endpoints and Payloads (接口路径与参数解析)
  - `chats.md`: Chat APIs
  - `models.md`: Model Administration APIs
- `patterns/`: Common API Patterns (通用设计模式)
